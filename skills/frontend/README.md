# Frontend

## Objetivo
Preparar a interface para visualização de mapas, dashboards e buscas por imóveis.

## Stack
- Next.js
- TypeScript
- React
- Tailwind CSS

## Diretrizes
- priorizar UI enxuta e escalável;
- separar componentes por domínio e responsabilidade;
- preparar o frontend para consumo da API e mapas geoespaciais.

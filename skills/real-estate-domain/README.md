# Real Estate Domain

## Objetivo
Consolidar o conhecimento do mercado imobiliário e as regras essenciais para modelagem de dados do domínio.

## Conceitos centrais
- anúncio
- imóvel
- localização
- bairro
- rua
- valorização
- preço por m²
- comparáveis

## Regras
- o nível de análise deve distinguir anúncio de imóvel real;
- preço de anúncio não é automaticamente valor de venda;
- o contexto geográfico influencia a avaliação.

# Decisões de arquitetura

Este diretório deve registrar decisões importantes da arquitetura do projeto.

## Registros esperados
- escolhas de stack;
- padrões de camada;
- decisões de dados geoespaciais;
- separação de módulos;
- justificativas de uso do Docker e do PostGIS;
- decisões de evolução do sistema.

## Formato sugerido
- título;
- contexto;
- decisão;
- consequências;
- data.

## Importância
As decisões devem ser legíveis por agentes de IA e desenvolvedores para manter coerência ao longo do projeto.
